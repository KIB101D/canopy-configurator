# Canopy Configurator

Параметричний 3D-конфігуратор дерев'яного навісу (канопі), побудований на чистому Three.js без додаткових 3D-фреймворків.

Користувач задає ширину, висоту та глибину навісу (2–8 м), закриває будь-які прольоти стінами різних типів, додає комору з дверима — і сцена перебудовується в реальному часі з коректним розташуванням усіх конструктивних елементів. Поряд із 3D є 2D-креслення плану з розмірними ланцюжками.

## Технології

- **Three.js** - рендеринг 3D-сцени, без React Three Fiber чи інших надбудов
- **TypeScript** (vanilla, без UI-фреймворка)
- **Vite** - збірка та dev-сервер
- Геометрія каркаса - `.obj`, матеріали - `.glb` (`Canopy_Materials.glb`)
- Стіни, двері, скло, ламелі - параметричні моделі, що генеруються в коді
- `CSS2DRenderer` - HTML-підписи розмірів у 3D, SVG - 2D-план

## Можливості

**Розміри**
- Ширина / глибина / висота 2–8 м: поле вводу, кнопки ±0.1 м і повзунок
- Значення поза діапазоном підсвічуються попередженням і обмежуються

**Стіни** — для кожної з 7 сторін (2 торці, 4 бокові прольоти, перегородка посередині):
- Дерев'яна обшивка з горизонтальних дошок (видно шви, зсередини — стійки)
- Дерев'яна стіна з дверима: коробка, засклена верхня частина з розкладкою, філенка з вагонки, ручки з обох боків, петлі
- Розсувна скляна стіна: алюмінієві напрямні, 2+ панелі у двох доріжках, ручки
- Ламельна перегородка з вертикальних рейок 45×45 на ригелях
- Вибір через міні-план: обираєш тип, клікаєш по стороні (повторний клік — знімає стіну)
- У прольотах зі стінами кутові розкоси прибираються автоматично; під перегородку ставиться ригель

**Комора** — пресет, що закриває передній або задній проліт:
- Двері на довгій стороні, у торці або в перегородці
- Дощата підлога всередині
- Зайняті коморою сторони на міні-плані заштриховані й не редагуються

**Вигляд**
- 3D-розмірні лінії в см (осі колон, дах, чисті прольоти, висота, загальна висота); підписи, закриті конструкцією, стають напівпрозорими
- 2D-план: контур даху, колони, стіни умовними позначками, дуга відкривання дверей, розмірні ланцюжки в мм, легенда
- Панель інструментів: повноекранний режим, 2D/3D, зум, розмірні лінії, скидання камери
- Перемикач реальних матеріалів (дерево/асфальт/алюміній) ↔ сірий заповнювач
- Тіні, освітлення через environment map (відбиття на алюмінії та склі)
- Конфігурація зберігається в URL-хеші — посиланням можна поділитися
- Адаптивна розкладка для мобільних

## Структура проєкту

```
src/
  canopy/
    dims.ts                    - тип Dimensions
    config.ts                  - CanopyConfig, типи стін, сегменти між колонами, комора
    loadModel.ts               - завантаження .obj геометрії та .glb матеріалів
    createCanopyEngine.ts      - сцена, світло, тіні, камера: init(), update(config), ...
    helpers/
      createBeamBetweenPoints.ts - балка між двома точками
      createParallelBeams.ts     - ряд паралельних балок
      createDeckingBoard.ts      - дошка настилу/покрівлі
    build/
      buildFrame.ts               - колони + кутові розкоси (з урахуванням стін)
      buildRimBeam.ts             - контурна балка периметру
      buildFasciaLayers.ts        - внутрішній і зовнішній фриз
      buildRoofStructure.ts       - настил, крокви, вставки
      buildRoofEdgeAndRoofing.ts  - профіль периметру та покрівля
      buildWalls.ts               - розстановка стін по сегментах, ригель, підлога комори
      buildDimensionLines.ts      - розмірні лінії та підписи в 3D
    models/                       - нові параметричні 3D-моделі
      primitives.ts               - woodBox / plainBox з UV у реальних метрах
      partMaterials.ts            - скло, фурнітура + сірий режим
      createTimberWall.ts         - дерев'яна стіна (+ проріз під двері)
      createDoor.ts               - двері з коробкою, склом і ручками
      createGlassSlidingWall.ts   - розсувна скляна стіна
      createSlatScreen.ts         - ламельна перегородка
  plan/
    renderPlan.ts               - 2D-креслення плану (SVG)
  ui/
    wallPicker.ts               - інтерактивний міні-план для вибору стін
    icons.ts                    - іконки панелі та типів стін
    shareLink.ts                - конфігурація ↔ URL-хеш
  main.ts                     - стан, панель-акордеон, панель інструментів
  style.css
index.html
```

### Як додати новий тип стіни

1. Додай id і підпис у `WALL_TYPES` (`config.ts`).
2. Створи модель у `models/` — функцію `(span, height, materials) => THREE.Group` у локальних координатах: `x` від 0 до `span` уздовж стіни, `y` вгору, `+Z` назовні.
3. Додай `case` у `createWallModel` (`buildWalls.ts`), іконку в `ui/icons.ts` і позначку в `plan/renderPlan.ts`.

## Джерело моделей

Усі `.obj`-моделі та `Canopy_Materials.glb` - надані як частина технічного завдання. Стіни, двері, скло та ламелі змодельовані параметрично в коді й використовують ті самі матеріали.
